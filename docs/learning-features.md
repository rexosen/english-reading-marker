# 学习功能 1.3 实施范围

Windows 与安卓均增加：生词卡片（原句、揭示释义、三档评分、到期复习）；逐句播放（高亮、上下句、循环次数、句间停顿）；字号/行距/阅读宽度/配色与本机自选背景图；全文搜索、分组、置顶、已读；句段收藏、译文与笔记编辑、回原文；备份预览、恢复前保存现状。

学习记录、笔记和文章分类通过现有局域网同步；显示配置和背景图仅存本机。资料格式只做增量升级；原库先备份。Windows 备份恢复要求退出后重新打开，启动前处理待恢复快照；恢复前显示条目数量并确认。安卓支持自动本机快照及文件导出导入，保留未同步数据副本。

本次用户未要求测试，不新增或运行自动化测试；构建、资料迁移和必要运行检查记录实际结果。安卓安装、系统语音与图库选择仍需真机确认。
