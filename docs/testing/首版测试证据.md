# 首版测试证据

## 来源与用户流程

测试范围来自首版需求和用户指定的 `assets/Online_Classes_原文.txt`。覆盖导入/预置文章、选择单词、给指定位置划线、联网查词反馈、生词保存、重开后保留划线、CSV 导出。

## TDD 记录

1. 先写领域、SQLite 仓储和 CSV 导出用例。
2. 首次运行时，缺失的 `src.domain`、`src.repository` 和 `src.exporter` 导致预期失败。
3. 实现最小数据层与界面后，测试逐项通过。
4. 增加 Windows CRLF 导入用例时，发现 Qt 文本框会把未规范化的换行显示成额外空行；导入前统一换行后通过。

## 验证结果

命令：

```powershell
.\.venv\Scripts\python.exe -m coverage erase
.\.venv\Scripts\python.exe -m coverage run --source=src -m unittest discover -s tests
.\.venv\Scripts\python.exe -m coverage report -m
```

结果：30 项自动化测试通过；`src/` 行覆盖率 91%。其中 `main.py` 91%、`dictionary.py` 95%、`repository.py` 88%、`domain.py` 91%、`exporter.py` 100%。

## 手动与打包验证

- 调用在线接口查询 `infrequent`，收到中文结果“ 不频繁 ”；接口文档允许用 GET 请求发送要翻译的单词，语言对参数格式为 `en|目标语言`。
- 启动最终 Windows 11 运行包，确认窗口打开并自动载入完整的 `Online Classes` 文章。
- 在界面中对文章中的一个 `students` 实例划线，检查本地 SQLite 只记录该实例的一组起止位置。
- 压缩包中确认包含 EXE、使用说明和样例文章，且不含会导致 Qt 启动失败的不兼容 ICU 副本。
